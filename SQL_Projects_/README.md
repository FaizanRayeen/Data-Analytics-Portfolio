## 🛠️ Concepts & Skills Demonstrated

* **Window Functions**: `RANK()`, `DENSE_RANK()`, `SUM() OVER()`, `LAG()`.
* **Common Table Expressions (CTEs)**: Modular query structures for complex multi-step analytics.
* **Relational Schema Design**: 5-table relational databases with primary/foreign key constraints.
* **Conditional Aggregations**: `CASE WHEN` for order status ratios, delivery SLAs, and customer spend buckets.
